## 🚀 Key Features

1. **Luxury Dark & Gold Theme**: Premium fast-food aesthetic with smooth animations and responsive layout.
2. **Interactive Size & Portion Selectors**: Dynamic live price calculation for Pizzas (Small/Medium/Large), Broast (Quarter/Half/Full), Pastas, Soups, Drinks, and Cakes (1 Pound/2 Pound).
3. **Dedicated Bakery & Sweets Section**: Separate catalog showcasing celebration cakes per pound, molten lava cakes, royal Arabic kunafa, brownies, and donuts.
4. **Dual Synchronized Cart**: Header slide-out drawer + in-page order tray with quantity steppers.
5. **1-Click WhatsApp Order Routing**: Directly formats the selected items, variants, and customer address into an itemized WhatsApp message sent to `0304-0700123`.
6. **Zero Dependencies**: Pure standalone HTML5, CSS3, and JavaScript — works instantly on GitHub Pages, Vercel, or local double-click.

## 🌐 Deploy to GitHub Pages

1. Create a repository on GitHub (e.g. `dough-delight`).
2. Push the files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Dough Delight Cafe"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Branch**, select `main` / `root` and click **Save**.
4. Your website is live at: `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`!

---

## 🌐 Deploy to Vercel

1. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
2. Import your GitHub repository.
3. Click **Deploy** (No build settings or framework preset needed — it deploys statically in seconds).
